# Your Bookmarks Are Not a Learning System

Every week you save links: an article a colleague sent, a video someone recommended, docs you swear you'll read. The count goes up. The learning doesn't.

Saving a link feels like progress because it's a decision you get to defer. Future-you will handle it. Future-you, of course, has a full-time job.

## Why link collections fail

It isn't a discipline problem. It's a structure problem. Collections fail for four predictable reasons:

- **No order.** A folder of 40 React links is not a curriculum. Nobody knows whether to start at link 1 or link 27, and neither do you.
- **No outcome.** "Learn Rust" isn't a goal, it's a mood. Without a concrete outcome — something you want to be able to *do* — you can't tell which links matter, so you keep them all.
- **No filter.** Collections grow by addition and never shrink. The 12 half-bookmarked tutorials from 2023 sit next to the one great guide you actually use, and the signal drowns.
- **No audience.** A private pile is easy to neglect. The moment someone else depends on your links — a new hire, a friend, a student — you're forced to order them, cut them, and make them make sense. Teaching is the best curation tool there is.

## The four-step system

The fix is boring and it works:

1. **Capture to one inbox.** Bookmarks, tabs, saved posts, that screenshot of a link — funnel everything into a single place. Scattered capture is how things get lost in the first place.

2. **Curate weekly.** Once a week, empty the inbox. For each link: promote it into a path, or delete it. The bar is high on purpose — when you're curation-mode, ask "would I send this to a colleague as *the* starting point?" If not, delete. Five excellent links beat fifty plausible ones.

3. **Order deliberately.** Sequence is where value gets created. A path should read like instructions: orient first, core material next, practice after that, depth last. If you can't explain why link 3 comes before link 4, one of them doesn't belong.

4. **Share the URL.** Publish the path. Send it to the friend who asked, the new teammate, the internet. A shared path forces the last mile of clarity — dead links get fixed, gaps get filled, hand-waving gets cut — and it keeps you honest: nothing decays faster than a link a colleague is depending on.

## Start with one topic

Pick one thing you're "learning" right now. Find the five links that actually moved you forward. Put them in order. Share the path with the person who'd benefit most.

That's the whole system. The bookmarks were never the problem — the missing structure was.
