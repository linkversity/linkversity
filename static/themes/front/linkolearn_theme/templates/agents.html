How to add Linkversity MCP

Two minutes: add the server, connect your account, then just ask.

  1. 1

    Add the server

    In your MCP client's settings (Claude, Cursor, ChatGPT, anything that speaks MCP), add a streamable-HTTP server with this URL:

    https://linkversity.lol/mcp
    Show the JSON config 
    {
  "mcpServers": {
    "linkversity": {
      "type": "streamable-http",
      "url": "https://linkversity.lol/mcp"
    }
  }
}
  2. 2

    Connect your account

    Public search works with no sign-in at all. The first time you reach for a personal tool, your client opens Linkversity's consent screen: approve once and it gets collections:read + collections:write. Your client fetches and refreshes the token itself (7-day access, 90-day refresh), so you never handle credentials.

  3. 3

    Start asking

    Natural language is the whole interface:

    “Find public collections about systems design, then save this article to my Backend collection.”

Give your agent the Linkversity skill

One SKILL.md: endpoint, all 7 tools with their scopes, the save-by-name workflow and the guardrails. Point your agent's skill loader at it, or drop the markdown into its skills folder as SKILL.md.

Load the skill

https://linkversity.lol/agents/skill
  • All 7 tools: what each does, and which of collections:read / collections:write it needs
  • When to save by name (save_link_to_collection) vs by ID (save_link)
  • Guardrails: never invent IDs, idempotent saves, ownership enforced server-side
  • REST fallback under /api/v1 with the 120 req/min limit
